# 领域参数库（Domain Specs）

扩写前先在这里取槽位。**「必填槽位」缺一项即视为规格不完整**，必须填上（取自默认值或用户指定）；「领域坑位」写进文档的边界或已知坑一节，提前预防而不是事后 debug。

取值原则：默认值是本领域的稳妥选择，可直接采用；用户有明确偏好时以其为准并进假设清单。

---

## D1 · Web 单页 / 交互页面

**必填槽位**

| 槽位 | 默认值 |
|---|---|
| 文件形态 | 单 HTML 内联 CSS/JS，无构建 |
| 体积上限 | ≤ 100KB（不含素材） |
| 浏览器 | Chrome / Edge / Firefox 最近 2 个大版本 |
| 断点 | 移动 ≤700px，桌面 1440 基准，无平板专用断点 |
| 色板 | 主色 / 辅色 / 背景 / 卡片 / 主文本 / 次文本，共 6 个色值，全部写死 |
| 字号阶梯 | 12 / 14 / 16 / 20 / 24 / 32 px 六档，正文 16 |
| 间距刻度 | 4 / 8 / 12 / 16 / 24 / 32 六档 |
| 圆角与阴影 | 圆角 8–12px；阴影 0 2px 8px rgba(0,0,0,.08) |
| 交互反馈 | hover 120ms，状态过渡 200–300ms，均 ease-out |
| 键盘可达 | focus-visible 2px 主色描边 + 2px offset；Tab 顺序符合视觉顺序 |
| 状态持久 | localStorage，键名 <app>-<data>-v1，损坏时降级为空并 warn |
| 性能预算 | 首屏无网络请求；动画 60fps；无 layout thrashing |

**领域坑位**

- `100vh` 在移动端被地址栏撑爆 → 用 `100dvh`，退化 `min-height:100vh`。
- 移动端 `backdrop-filter` 低端机掉帧 → 多于 2 层毛玻璃时改用半透明纯色。
- `outline:none` 抹掉键盘焦点 → 只允许替换为 `:focus-visible` 样式，不许直接删。
- 用户输入走 `innerHTML` → XSS；一律 `textContent`。
- localStorage 在隐私模式/跨域 iframe 抛异常 → 全程 try/catch，失败降级内存态。
- 触摸事件同时挂 `touchstart` 与 `pointerdown` → 双触发；只用一个。

## D2 · 3D / Canvas / 图形渲染

**必填槽位**

| 槽位 | 默认值 |
|---|---|
| 渲染器 | antialias:true；pixelRatio 上限 2 |
| 色调映射 | ACESFilmic，曝光 1.0 |
| 阴影 | PCFSoft；贴图 2048²；阴影相机正交范围按场景尺度 ±40；bias −0.0004 |
| 后期链 | RenderPass → 泛光（强度 .35 / 半径 .6 / 阈值 .85）→ OutputPass |
| 雾 | 起 60 止 260，色随昼夜插值 |
| 相机 | FOV 50，near .1，far 1200 |
| dt 上限 | 0.05s（防切标签页回来瞬移） |
| 粒子上限 | 600（点粒子）/ 4000（2D canvas） |
| 三角形预算 | ≤ 30 万（软渲染要降到 3 万以内） |
| 资源策略 | 全程序化建模，不加载外部模型；纹理用 Canvas 生成 |

**领域坑位**

- 改颜色忘了 `needsUpdate` → 顶点色/实例属性全部不生效，显示成黑块。
- `UniformsUtils.merge` 会克隆 uniforms → 必须改 `material.uniforms`，改原对象无效。
- 阴影相机范围开太大 → 阴影糊成一片；每帧让阴影相机跟随主角。
- 泛光 + ACES 叠加过曝 → 材质基色整体调暗 15%，或阈值提到 .9。
- SwiftShader 软渲染帧率低 → 时间相关逻辑用 dt 累加，不用帧数计数；截图要直接设状态值。
- 大量 mesh 各自材质 → draw call 爆炸；同色同材质合并。

## D3 · 音视频 / 多媒体

**必填槽位**

| 槽位 | 默认值 |
|---|---|
| 视频分辨率 | 720p 生成，640 宽内嵌 |
| 视频编码 | H.264，CRF 30，preset slow，`-pix_fmt yuv420p`，`-movflags +faststart`，无音轨 `-an` |
| 音频 | 单声道 44.1kHz；语音 48kbps，音乐 56kbps |
| 循环处理 | 截取固定时长 + 首尾淡入淡出（in .5s / out 3s） |
| 图片 | 1280 宽 JPEG q≈4；或 PNG 无损（≤200KB） |
| 内嵌方式 | base64 → atob → Uint8Array → Blob → createObjectURL |
| 体积预算 | 单文件总计 ≤2MB；单素材 ≤600KB |
| 自动播放 | 首次用户手势内创建/恢复 AudioContext |

**领域坑位**

- CSP 拦 `data:` 媒体 → 必须走 blob URL，且不能用 `fetch(data:)`（connect-src 会拦）。
- 缺 `-movflags +faststart` → 网页里首帧迟迟不出。
- 缺 `-pix_fmt yuv420p` → Safari 黑屏。
- 循环音频接缝明显 → 必须做淡入淡出，或选天然可循环片段。
- 内联 base64 撑爆 HTML → 先压到目标体积再内联，压完复核字节数。

## D4 · Windows 脚本 / 文件批处理

**必填槽位**

| 槽位 | 默认值 |
|---|---|
| 幂等 | 重复执行结果一致；已处理的跳过并记日志 |
| 预演 | 默认 dry-run，`-Apply` 才真改；预演输出完整待办清单 |
| 冲突命名 | `原名 (1).扩展名` 递增，不覆盖 |
| 编码 | 脚本 UTF-8 BOM，读写显式 `-Encoding UTF8` |
| 路径 | 全程 `-LiteralPath`；支持中文与空格；长路径前缀 `\\?\` |
| 日志 | 时间戳 + 动作 + 源 + 目标，落 `logs/YYYYMMDD.log` |
| 回滚 | 移动操作记录反向映射表，可 `-Undo` |
| 排除 | 系统文件、隐藏文件、日志目录默认排除 |
| 失败策略 | 单文件失败不中断，末尾汇总失败清单与原因 |

**领域坑位**

- 中文用户名路径 + 单引号字符串 → `$env:` 不展开；含变量必须双引号。
- PowerShell 用 `&` 串联命令 → ParserError；用 `;` 或换行。
- `Move-Item` 同名静默覆盖 → 先判存在再加后缀。
- 删含 junction 的目录 → 跟随链接删空目标；先 `rmdir` 摘链接。
- 路径 >260 字符 → .NET 老 API 报错，用 `\\?\` 前缀或 `[IO.Directory]`。
- 通配符 `*` 匹配到隐藏文件以外的东西 → 用 `-File` + `-Filter` 双重限制。

## D5 · 后端接口 / 数据库功能

**必填槽位**

| 槽位 | 默认值 |
|---|---|
| 契约 | 路径 + 方法 + 入参（名/类型/必填/长度）+ 出参结构 + 错误码表 |
| 鉴权 | 会话/Token 方式明确；未登录返回码与文案 |
| 分页 | pageIndex 从 1 开始，pageSize 默认 20 上限 200；返回 total 与列表 |
| 事务 | 写操作显式边界；主从表同事务；失败整体回滚 |
| 幂等 | 写接口带幂等键（单号/请求 ID），重复提交返回首次结果 |
| 并发 | 乐观锁版本号或行锁；冲突返回码与提示 |
| 索引 | 每个查询条件对应索引名；过滤字段区分度说明 |
| 数据量 | 单表预估行数、单次查询最大返回、慢查询阈值 500ms |
| 超时重试 | 客户端超时 10s，只读重试 2 次（指数退避），写不自动重试 |

**领域坑位**

- 空串与 NULL 混用 → 查询条件永远不命中；入参统一空转 NULL 的规则要写死。
- 列表与 total 两次查询不一致 → 同事务或同快照读。
- 循环里查子表 → N+1；一次 `IN` 捞回内存组装。
- 分页用 `OFFSET` 深翻页 → 大偏移慢；用游标（上一页最后 ID）。
- 时间字段跨时区 → 统一存 UTC，展示层转本地。
- 写操作没提交事务 → 自测"成功"但库里没数据。

## D6 · 文档 / 长文写作

**必填槽位**

| 槽位 | 默认值 |
|---|---|
| 受众 | 明确到角色与前置知识（如"懂 SQL 但不懂业务"） |
| 篇幅 | 总字数区间 + 各节字数配比 |
| 结构 | 三级标题骨架逐条列出，不允许执行时自拟 |
| 语气 | 人称、术语密度、是否允许口语 |
| 事实来源 | 每条数据/结论标注出处（文件路径、命令输出、链接） |
| 必含 | 硬性要素清单（如必须含风险章节与验收标准） |
| 禁含 | 禁用词与禁用写法（AI 味排比、无出处数字、空洞形容词） |
| 交付格式 | Markdown / docx / 公众号 HTML；是否带 frontmatter |

**领域坑位**

- 只给主题不给骨架 → 产出结构随机，每次不一样。
- "专业严谨"无量化 → 执行者自由发挥；改成"术语首次出现给一句解释，不用比喻"。
- 事实没有出处 → 无法核验，读者不敢信。

## D7 · Agent / 工具链 / 自动化流程

**必填槽位**

| 槽位 | 默认值 |
|---|---|
| 工具与权限 | 每一步用哪个工具、是否需要写权限、是否需用户确认 |
| 失败降级 | 每个工具调用失败后的替代路径；连续失败上限 2 次 |
| 验证方式 | 每个阶段的判定依据（命令退出码 / 文件存在 / 内容断言） |
| 阻塞条件 | 什么情况下必须停下来问用户，不许自行决定 |
| 状态落盘 | 中间产物路径与命名，便于中断续跑 |
| 重试策略 | 只读重试，写操作不重试；重试必须改方法不许原样重放 |
| 幂等 | 重复执行不产生重复副作用 |

**领域坑位**

- 把"已完成"写成结论而没有验证证据 → 假成功；每条完成声明附可复核输出。
- 失败后原样重试 → 必然再次失败；必须换方法或降级。
- 中间产物只存内存 → 中断即全丢；关键节点落盘。
- 越权操作（删除/覆盖/发布）未经确认 → 先问。
