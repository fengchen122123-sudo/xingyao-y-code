# 八类任务的必补槽位

用法：先定主类，只补该类标为必补的槽位；次类只补它独有的项目。
不是所有槽位都要填——填不进去就问，问不出来就留 `[待填：…]`。

## 1. 编码改动

信号：加功能、改行为、重构、迁移、升级依赖。

- **改哪里**：文件、模块、入口，写真实路径，不写"相关文件"
- **现状与目标的差**：现在的行为是什么，期望的行为是什么
- **不变量**：哪些接口、数据结构、外部调用方不能动
- **验证方式**：测试命令、构建命令、手动复现步骤

最易漏：**不变量**。改完把别的功能搞坏，基本都是没写"什么不能变"。

## 2. 调试排查

信号：报错、结果不对、偶发失败、性能下降。

- **可复现的最小路径**：命令、输入、环境、数据
- **报错原文**：完整贴，不要转述
- **最近变更**：从哪次提交、哪项配置改动之后开始出现
- **判定修好的标准**：同一复现路径不再出现，且没引入新错误

最易漏：**复现路径**。没有它模型只能猜，猜出来的修复大概率不对症。

## 3. 研究调查

信号：查资料、对比方案、搞清楚某东西怎么工作。

- **问题边界**：要回答到什么深度，哪些不用管
- **来源等级**：官方文档 / 源码 / 论文 / 社区，优先级排好
- **输出形态**：结论加依据，还是要完整报告
- **时效要求**：必须是最新版本，还是任意版本都行

最易漏：**时效和来源等级**。不写，模型会混用过期博客和官方文档。

## 4. 分析判断

信号：看数据、评估方案、做取舍、排优先级。

- **判据**：按哪些维度比，权重怎么分
- **数据来源与口径**：哪份表、哪个时间段、含不含异常值
- **输出形态**：结论先行加支撑 / 对比表 / 决策建议
- **不确定时怎么写**：如实标注还是给区间，不许编

最易漏：**判据**。没有判据的"帮我分析一下"，必然得到一篇正确的废话。

## 5. 写作生成

信号：写文档、写方案、写文案、写报告、写邮件。

- **读者是谁，拿它做什么决定**
- **篇幅与形态**：一页 / 三千字；报告 / 清单 / 邮件
- **必须包含**与**必须避免**的具体内容
- **语气与参照样例**：给一段真实样例，比任何形容词都准

最易漏：**读者的用途**。写给谁、拿去干什么，决定详略和语气。

## 6. 设计前端

信号：做页面、改 UI、调交互、改样式。

- **目标设备与尺寸**：桌面 1440 宽 / 移动 375 宽
- **现有设计系统**：有没有 CSS 变量、组件库、品牌色、字体规范
- **具体禁止项**：不要什么渐变、什么配色、什么图标风格——越具体越好
- **验收方式**：截图对比？在哪个分辨率看？看哪些状态

最易漏：**现有设计系统**。不写，模型会发明一套，跟现有产品不搭。

## 7. 数据处理

信号：清洗、转换、统计、批量导入导出、生成报表。

- **数据在哪、多少量、什么格式**：给真实样本，不要描述
- **脏数据规则**：空值、重复、格式错乱、超范围，各怎么处理
- **输出格式与校验方式**
- **失败时怎么办**：跳过并记录，还是整体中止

最易漏：**脏数据规则**。只写正常路径，跑真实数据必崩。

## 8. 多步代理执行

信号：连续做很多步、要调工具、要跑很久、要无人值守。

- **终点状态**：全部做完是什么样
- **通过条件**：每步都要过，还是只有一个总验收
- **必须停下来的情况**：破坏性操作、动线上、花钱、对外发送
- **报告要求**：做到哪、卡在哪、还剩什么

最易漏：**停下来的条件**。不写，它要么一路蛮干，要么每一步都来问你。

## 通用补充槽位

| 槽位 | 什么时候加 |
|---|---|
| 输出语言 | 用户可能换语言，或提示词是英文但要求中文产出 |
| 文件落点 | 产物要存盘时，写绝对路径 |
| 禁止动作 | 有真实踩坑史时，并写清那次怎么出的事 |
| 参照物 | 有"做成类似 X 那样"的诉求时，把 X 的真实内容贴进来 |
| 硬性限制 | 限期、token 预算、只能跑一次、不能联网 |

## 归类不了怎么办

- **复合任务**（"先分析再改代码"）：按**最终产出物**归类，前置步骤作为上下文的一部分写进去。
- **说不清要什么**：缺的是目标本身。这时该做的是问清楚，不是改写。
- **没有产出物的口头描述**：多半属于研究或分析，按"要回答什么问题"归。
