# 星瑶 内置生图后端

本文档只服务于一个场景：当前运行时是 **星瑶**，即工具清单（tool inventory）里同时暴露 `hunyuan_generate_image` 与 `tokenrhythm_generate_image`。此时这两个原生工具就是本技能的位图后端，优先级高于任何非原生技能（包括未安装的 `baoyu-image-gen`）。

## 1. 适用场景

- 运行时判定：工具清单中出现 `hunyuan_generate_image` 或 `tokenrhythm_generate_image`，即命中 星瑶 分支。
- **默认用混元**：`hunyuan_generate_image` 是内置免费后端，没有特别理由时一律用它。
- **改用基元**（`tokenrhythm_generate_image`）的四种情况：
  1. 用户在本次请求里明确点名「基元」/ `tokenrhythm`；
  2. 需要更接近 3:4 的竖版尺寸；
  3. 一次想要 2-4 张候选图；
  4. 需要指定模型（`model`）。
- 硬性禁止：
  - 禁止用 SVG / HTML / canvas 等代码化渲染冒充位图输出；
  - 禁止用 ImageMagick、Pillow、canvas、OCR 脚本等手段程序化叠加、覆盖或修补已生成图片里的文字（标题、副标题等）。文字有问题时改 prompt 重新生成，或换无标题/少文字的版式。

## 2. 参数映射表

| 语义 | 混元 `hunyuan_generate_image` | 基元 `tokenrhythm_generate_image` |
| --- | --- | --- |
| 提示词 | `prompt` = prompt 文件的完整内容 | `prompt` = prompt 文件的完整内容 |
| 输出目录 | `save_dir` = 技能约定的输出目录（如 `outputs/.../`） | `save_dir` = 技能约定的输出目录 |
| 张数 | 一次调用 1 张 | `n` 支持 1-4（每张 ¥0.20，使用前先与用户确认张数） |
| 模型 | 无此参数 | `model`：`qwen-image-2.0`（默认）/ `wan2.7-image` |
| 水印 | `footnote`（默认空格 = 无水印） | 无此参数；水印只能写进 `prompt` 文本 |
| 参考图 | `image=<本地路径>` | `tokenrhythm_edit_image(image=<锚图路径>, prompt=<改图指令>)` |

## 3. 尺寸映射表

只允许使用工具真实支持的取值，不要臆造。

- 混元支持：`1024x1024`、`1280x720`、`720x1280`、`1280x1280`
- 基元额外支持：`1024x1792`、`1792x1024`

| 目标比例 | 选用尺寸 | 说明 |
| --- | --- | --- |
| 1:1 | `1024x1024` | 精确 |
| 16:9 | `1280x720` | 精确 |
| 9:16 | `720x1280` | 精确 |
| 3:4 | `1024x1792` | 只能近似 3:4（更瘦长），不要声称是精确 3:4 |
| 2.35:1 | `1792x1024` 或 `1024x1792` 中更接近横幅的那个 | 必须注明是近似值 |

## 4. 批量与锚图链

- 一批最多并行 4 张混元调用（`hunyuan_generate_image` 每次 1 张，可并发发起）。
- 基元可以一次 `n=4` 拿到 4 张候选。
- 第 1 张成功后，如果后续封面/卡片需要保持风格一致：把第 1 张的本地路径传给 `image` 参数当参考图（基元则走 `tokenrhythm_edit_image`），形成锚图链。

## 5. 失败处理

- 混元调用失败：如实向用户报错，可改用基元重试**一次**。
- 基元未配置（插件未启用，或缺少 base_url 含 `tokenrhythm.studio` 的提供商 Key）：提示用户去插件页 / 设置页完成配置，**不要反复重试**，**不要伪造生成结果**。
- 任何密钥（API Key、token 等）都不得写入文件，也不得在对话中输出。

## 6. 展示要求

生成成功后，必须用 Markdown 图片语法展示结果，路径指向本地文件：

```markdown
![](outputs/.../NN-xxx.png)
```
