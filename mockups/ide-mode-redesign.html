改动点与落地说明

下面每一项都标注了性质：新增 / 沿用 / 待定，方便你按优先级挑要做的部分。

入口：顶栏 IDE 切换按钮 沿用

按钮已存在于 Topbar.vue（#btn-ide-mode，store.toggleIdeMode()）。 设计稿只把激活态做成强调色胶囊（--accent-soft 底 + --accent 边框与文字）， 让「当前处于 IDE 模式」一眼可见，不再是纯文字按钮。

布局骨架 沿用

IdeLayout.vue 已有「活动栏 + 侧栏 + 编辑器区 + 对话区宿主」四段结构， 对话区经 Teleport 从 App.vue 搬入，只有一份 DOM。本次不改这套机制， 只调尺寸与视觉：活动栏 48px、侧栏 246px、对话区 368px。

底部状态栏（IDE 态） 新增

  • 左段沿用现有 #statusbar 项：连接、模型、工作区、Token、权限、沙盒、AI 声明。
  • 新增右段编辑器态：问题计数、行 / 列、缩进、编码、换行符、语言，数据来自 CodeMirror 光标状态。
  • 最左新增 IDE 徽标，提示当前模式。

工作区空状态 新增

未打开项目时，现在只显示一句「从左侧文件树打开文件」。设计稿换成 VS Code 式欢迎页： 打开文件夹 / 新建项目 / 克隆 Git 仓库 / 连接远程主机 / 新建文件，加最近打开列表与快捷键提示。 左侧资源管理器同步显示「尚未打开文件夹」空状态。

资源管理器分区 新增

文件树之下补「大纲 / 时间线」两个可折叠区段：大纲读 LSP 文档符号（core/lsp.py 已有能力）， 时间线读 Git 记录。落地可分两步，先接大纲。

活动栏图标 新增

现状只有文件 / Git / 调试三个。设计稿扩到七个：资源管理器、搜索、源代码管理、运行调试、扩展、星瑶、设置。 图标全部走现有 iconPaths.ts 注册表，不引入图标库。搜索与扩展面板可后置。

右侧对话区 新增

  • 新增头部：星瑶头像 + 当前会话名 + 新会话 / 历史 / 收起三个操作。
  • 消息区复用现有消息组件；工具执行卡在窄栏里改为紧凑样式（文件名 + 增删行数 + 可展开 diff）。
  • 输入区复用现有输入框逻辑，窄栏下压缩为两行（输入 + 控件条）。
  • 空会话显示欢迎页，与 TRAE 的欢迎区结构对齐，文案与强调色换成星瑶的蓝色。

编辑器区 沿用

标签页、面包屑、代码区沿用 EditorTabs.vue / EditorPane.vue / BottomPanel.vue， 仅统一视觉：标签顶部 2px 强调线、未保存圆点、面包屑显示当前符号、底部面板标签加计数。

菜单栏 待你定

TRAE 截图里有「文件 / 编辑 / 查看 …」菜单栏。星瑶顶栏是自绘的 frameless 标题栏（48px，含窗口控制）， 再加一行菜单栏会变成两行、且需要新做整套菜单数据。 我的建议：默认不加，用 Ctrl+P 命令面板 + 活动栏承担这些入口； 你要是想要，用上面开关看看效果再定。
