这版设计的关键点
  • 工具行 = 图标 + 类别（读取 / 运行 / 编辑 / 搜索）+ 目标 + 状态/耗时 + 悬停箭头，整行无边框无底色。
  • 行宽贴合内容（width: fit-content），不铺满整行；悬停整行轻微浅底，提示可点。
  • 详情挂在行下面：左 1px 细线 + 14px 缩进 + 最弱灰，限高内滚，和思考块同一套语言。
  • 运行中不转圈，靠类别标签轻微扫光 + “运行中”状态词；失败用红色状态词 + 虚线下划线，悬停看完整报错。
