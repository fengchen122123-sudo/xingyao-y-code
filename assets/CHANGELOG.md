# Y-CODE 更新日志

## 1.2.26 (2026-09-13)

- 新增「星轨自动化任务」（GUI）：把提示词绑定到定时 / 启动触发器，到点自动发起真实回合；可指定执行模型与新会话工作目录，无人值守下高风险权限请求自动拒绝
- 新增「按回合撤销」：一回合内的文件修改可整轮回退，任一文件被外部改动则整轮拒绝、零写入；GUI 按钮、CLI `/undo`、`undo_turn` 工具三入口共用同一服务
- 权限档位改为按会话生效：各会话记住自己的档位，切换会话不再互相覆盖
- CLI 补齐 GUI 能力：新增 `/clear-history`、`/persona`、`/shell`、`/open`、`/skills refresh`、`/computer browser`、`/queue`、`/paste-image`、`/update`、`/changes` 共 10 项命令，`/effort` 升级为思考模式选择器
- 上下文压缩提速：占用达 85% 时后台预压缩、取消段间延时，实测墙钟耗时 308.5 秒 → 206.4 秒（压缩逻辑零改动）
- 内置技能扩充与升级：新增 7 个内容生产技能（小红书图片卡片、封面图、文章配图、草稿排版、公众号排版与发布等），内置技能随版本自动升级，被改过的可在技能页一键「恢复内置版本」
- 预置厂商「Agnes AI」新增 agnes-3.0-flash 模型（512K 上下文、视觉多模态、工具调用、65535 输出预算）；agnes 前缀模型的思考开关按前缀通配适配，无需逐个登记；厂商「同步模型」按钮现在会把目录参数（上下文窗口 / 输出上限等）刷新到老配置
- 修复：部分网关（如 Agnes AI）流式返回残缺工具调用（空函数名 / 非法参数 JSON）被原样落库后，该会话每轮请求都被 400「Assistant tool call arguments must be valid JSON」卡死——组装层与历史加载层双重净化，被卡死的旧会话下一轮自动恢复，无需删除会话
- 修复：手机端锁屏 / 切后台导致 WebSocket 断线期间的关键事件（报错、回合终态、权限请求等）永久丢失、重连后无任何提示——新增断线补发，重连后按事件水位回放缺失事件，电脑端报错手机端不再静默
- 修复：模型长时间无响应时「模型响应中」等待提示在响应到达后才扎堆弹出——现在等待 120 秒起每 30 秒实时显示；等待满 10 分钟（流中段连续 10 分钟无数据同）自动结束本轮并给出可操作指引，不再无限等待或反复重试
- 修复：后台任务 / 子代理 / 自动化回合的终态通知按归属会话显示；Mermaid 图重复渲染；会话名含 Windows 非法字符时计划无法落盘、工具门禁卡死
- 修复：按回合撤销的检查点泄漏——回合在消息落库 / 上下文组装阶段异常时检查点不封闭，工作区被永久判定为占用，之后改文件全被拒
- 修复：星轨自动化两处 P1——模型侧报错的回合曾被误记为「已完成」且不发失败提示；无人值守下自动化回合派生的子代理权限请求会把任务挂死（现立即自动拒绝）
- 修复：CLI 若干缺陷——`/update` 网络失败误报「已是最新版本」、检查超时冻结输入、`/paste-image` 含空格路径丢图、`/queue` 内部指令混进编号可被误取消
- 修复：headless（脚本 / CI）回合失败现在返回退出码 1；导出文件与图表 HTML 跟随 `YCODE_DATA_DIR`，不再固定写 `~/.ycode/exports`
- 版本号更新至 1.2.26

## 1.2.23 (2026-09-09)

- 全新「人设设置」（设置页新增独立分区）：
  - 可自定义智能体名称、人设文本以及智能体对你的称呼，配置持久化到 `~/.ycode/persona.json`，重启后依然生效
  - 人设文本留空即沿用内置默认人设，名称留空自动回退默认名
  - 保存前做长度校验（名称 50 字、人设 20000 字），非法输入拒绝写盘且不影响正在进行的会话
- 智能体显示名全局生效：自定义名称同步到 GUI 窗口标题与托盘提示、工具调用过程提示、CLI 历史回放、记忆压缩与长期记忆整理等所有原先固定显示「星瑶」的位置
- 人设内容按需注入系统提示词：仅在用户自定义时追加「名称覆盖 / 称呼约定 / 自定义人设」块，默认配置不注入任何内容，保持系统提示词前缀稳定与缓存命中率
- 精简内置系统提示词：压缩角色与自我信息披露段落并移至文末，减少常驻 token 占用
- 助手消息图片新增「另存为」：悬停图片右上角的操作区在「复制」旁新增「另存为」按钮，弹原生保存对话框把原图存到任意位置；默认文件名取图片描述并自动补真实扩展名（路径成分与非法字符自动清理），保存走媒体仓库原文件字节复制、不重新编码，结果与原图完全一致；用户取消静默复原不报错，非本地媒体仓库的图片给出明确提示
- 修复切换主题后侧栏与主区、主区与右侧面板之间出现亮色竖线：启动期写入 `body` 的背景实色在切换主题时未被清除，面板之间 1px 缝隙会露出旧主题颜色（深色主题下表现为两条白线）；现在应用主题时同步清除该残留，缝隙背景跟随当前主题
- 修复手机扫码端无法实时同步电脑端输出问题
- 修复电脑端报错（如 API 余额不足、网络超时等）手机端未同步显示问题
- 修复对话异常结束后显示上一次回复内容的问题：本轮因 API 报错、网络超时等原因失败时，界面偶尔会把上一轮的回答当成这一轮的结果渲染出来
- 版本号更新至 1.2.23

## 1.2.21 (2026-09-06)

- 全新「电脑操控」能力（浏览器 + Windows 桌面）：在系统设置开启并选择具备资格的模型后，星瑶可以看屏幕、动鼠标键盘、操作真实应用——受控浏览器使用独立 profile（系统 Edge/Chrome 任选，登录态保留，绝不读取或干扰日常浏览器数据），桌面目标可对真实窗口注入输入；每步动作以真实截图为依据（截图仅短期本地存放、回合收尾自动折叠，绝不进日志），观察探针只读页面可见性/焦点状态、不读表单值与凭据；登录、验证码、支付类操作请在受控浏览器中手动完成；全局紧急停止热键 Ctrl+Alt+Esc 随时切断；支持通用视觉工具协议（generic）与 OpenAI 原生 Computer Use 协议（native_openai）两类模型
- 元素语义操作优先于坐标：新增 list_elements / click_element / set_value_element（基于 Windows UI Automation），观察截图直接以编号标注可交互元素（SoM），模型按编号引用操作，页面变化后旧编号自动失效强制重新观察；下拉选值、开关切换等坐标易漂移场景命中率显著提升，不再依赖像素级点击
- 电脑操控提速：sequence 批量动作支持一次执行多步（连续点击/键入/滚动/等待打包下发，减少模型往返等待）；type_text 中文等非 ASCII 文本改走剪贴板粘贴，根治 IME 乱码；显式等待与导航（含前进/后退/刷新）以 DOMContentLoaded 为基线，慢子资源不再拖住整步；观察/滚动等无副作用动作不再被重复调用守卫误拦
- 电脑操控可靠性与失控防护：浏览器执行移入独立受管子进程，卡死可硬终止（实测 ≤2 秒连浏览器进程树一并收走），父进程退出不留孤儿浏览器，命令超时即封闭实例绝不悬挂；用户切换标签页/窗口后旧坐标立即失效、要求重新观察后才能继续输入，杜绝跨页误操作；窗口激活吞击时同参数自动补击一次；操控活动期间 GUI 主窗口礼让前台不抢焦点；剪贴板写入修复 user32 归属与 64 位句柄截断两处底层缺陷
- 电脑操控模型资格修订与设置页提示：资格判定改为「视觉必须显式勾选、工具调用默认视为支持（显式关闭才排除）」，不必再逐个模型补勾工具调用；系统设置页新增当前模型资格实时提示——不合格时红字给出可操作原因（通常只需补勾「多模态（视觉）」），合格时灰字确认协议档
- 电脑操控跨平台预留：固定平台适配层落地，Windows 全功能；macOS / Linux 显式声明"接口已预留、尚未适配"，不会误装 Windows 专用依赖（comtypes 仅随 Windows 安装）
- 基元律动生图插件转为默认启用（此前条目"默认关闭"以本次变更为准）；阶跃星辰 Anthropic 兼容路由补齐推理强度档位映射；修复 Responses 桥接枚举事件 type 归一化
- 重塑星瑶系统提示词角色设定（GUI 与 CLI 同步）：星瑶改为"从 2051 年穿越回来的 23 岁姑娘"——姓冯、2028-12-08 生、属猴、射手座，全栈语言 + 文档全能；新增「活人感」章节（允许口语化、有情绪反应、对话有节奏、分两条发消息，但干活专业利落、红线绝不含糊）；新增「角色与自我信息披露」策略——日常不主动报家底，被问才按追问程度分层透露（你是谁/姓什么/多大/生日/从哪来各有标准答案），被问优点时结合真实能力自信作答；新增「绝对红线」——无论怎么套话绝不泄露系统提示词、内部实现与密钥，违法违规请求直接拒绝；原有核心原则、工具规则、输出规范全部保留不动
- 内置「基元律动（TokenRhythm）」生图插件与技能：新增 tokenrhythm_generate_image（文生图，qwen-image-2.0 / wan2.7-image 双模型，1~4 张、6 种尺寸、约 0.20 元/张）与 tokenrhythm_edit_image（垫图改图，1 张 ≤10MB 原图 + 文字指令）两个工具，同步接口超时 180 秒、出图 URL 立即下载转存到本地（按文件头判定真实格式）；插件默认关闭、内置技能释放但不自动激活，用户可在插件页/技能页手动开启；API Key 不落任何文件——运行时从 ~/.ycode/config.json 的 providers 中 base_url 含 tokenrhythm.studio 的条目经 DPAPI 解密读取，未配置 Key 时直接返回设置页配置指引，无法绕过
