# Y-CODE 更新日志

## 1.2.18 (2026-08-30)

- 修复回复「尾部缺一段」的流式丢失问题：回合收尾改为先冲刷缓冲再清理，并补发 `message_final` 全文事件；前端只在最终全文更完整时校正显示，避免快模型最后一块文本静默丢失
- Agent 循环新增确定性无进展熔断：连续重复读取、重复工具调用或状态没有真实变化时会明确停止并说明原因，不再无限循环、空耗 Token；计划状态机工具保留必要的连续调用能力
- 单任务最大模型轮次支持在「系统设置」中配置（10–1000，默认 100）；达到上限时任务明确标记为未完成并保留已产生的代码、工具结果和测试记录，不再把截断任务错误显示为已完成
- 修复内部协议占位文本泄漏到回复、数据库和历史回放的问题；达到轮次上限、Provider 异常或无进展熔断时统一走失败终态并发送 `turn_error`，不再被后续完成事件覆盖
- 子 Agent 首次超时后改由主 Agent 原地接管，保留已经完成的工作和现场，不再重新派发同一计划项；多个超时任务按 FIFO 排队，跨回合、重启、验证失败和用户取消均有明确恢复或终止出口
- GUI 计划面板和工具卡片新增「主 Agent 已接管 / 等待主 Agent 接管」状态，接管队列、负责人和原因可恢复展示，旧子 Agent 卡片保持真实的超时状态
- 后台任务管理新增稳定的 `list/status/wait` 协议、revision 条件等待和终态快照；任务完成、失败、取消、日志增长及进程自然退出都会推进版本，终态记录有界保留且不会被轮询意外复活
- 修复后台任务启动后误显示「命令执行完成」的问题，现明确显示「后台任务已启动」；终止任务会区分已终止、自然退出、身份无法确认和终止失败，避免误报成功或结束错误进程
- 加固计划执行租约：运行字段只允许调度器修改，执行中或等待接管的计划项禁止改写任务描述、文件范围和验证方式；状态与租约模式通过锁内 CAS 原子校验，消除并发认领期间旧快照覆盖新状态的竞态
- 计划调度新增文件租约账本，委派、接管、恢复、提升、取消和关闭均按认领时的不可变文件集合释放资源；修复文件范围变化导致旧锁泄漏，以及崩溃恢复后的接管任务未持有文件锁的问题
- 权限系统统一四种模式与任务/项目授权：写入、编辑、命令和工作区外访问可按当前任务或整个项目记忆授权；凭据文件仍强制单独确认，计划模式和沙盒边界不能被白名单绕过
- 新增 `config.toml` 只读兼容层：可在 `~/.ycode/config.toml` 中覆盖 `config.json`，字典递归合并且 TOML 优先；所有界面和命令写回仍只修改 JSON，同名键被 TOML 覆盖时会留下明确告警
- 撤销功能改为保存并原子恢复文件原始字节，正确保留 GBK、UTF-8、CRLF 等编码与换行；新建文件可通过强制撤销删除，覆盖大文件也能恢复，不再受普通写入大小保护误拦截
- 回合文件检查点支持跨线程绑定，主 Agent、并行工具和子 Agent 的修改能归入正确会话与 Turn；已结束回合会拒绝迟到快照，避免撤销记录串会话或被后台线程污染
- 手机远程控制配对 token 支持持久化和「永久有效」模式，永久链接不再进入倒计时自动刷新；刷新 token 仍会立即作废旧连接
- 修复 Markdown 行内代码跨行误匹配：孤立反引号不再吞掉后续表格或列表；同时修复 GUI 启动时最大化状态不同步、手机端主题编辑器控件溢出，以及会话模型选中态被全局快照错误覆盖的问题
- `evaluate_js` 事件投递失败日志由 debug 升级为限频 warning，渲染层投递问题可以直接从运行日志定位

## 1.2.17 (2026-08-28)

- 修复手机远程控制报「后端连接失败：pywebview API 不可用」：1.2.16 安装包漏打包 mobile-shim.js（手机端 WebSocket 桥接脚本），手机页面脚本 404 导致永远无法连接；安装包已补齐该文件，且服务端新增内嵌兜底——即使磁盘文件缺失也会返回内置快照，彻底杜绝此类 404

## 1.2.16 (2026-08-27)

- 安全加固：手机远程控制「刷新」二维码后立即断开所有旧 token 连接并作废旧配对链接（此前已连接的手机在刷新后依然可控，二维码泄露无法补救）；token 校验与客户端注册改为原子操作，杜绝重签瞬间竞态
- 手机端新增「进入项目工作区」内置文件夹浏览器：可逐层浏览电脑盘符与目录并直接引入为项目工作区（此前该入口被桌面专属黑名单拦截报"未知方法"）；桌面端保持原生文件夹对话框不变
- 浏览器标签页标题简化为「星瑶」
- 新增局域网手机远程控制：侧栏手机图标扫码即可在手机端实时同步对话、发消息、处理权限
- 手机远程控制配对 token 改为一次生成后固定复用（应用重启不变），过期自动重签，弹窗新增「刷新」按钮与有效期倒计时
- 手机端模型选择菜单重做为 ZCode 式双栏：主面板窄版靠右、当前供应商模型内联直选，其他供应商在左侧独立方盒展开，超长名称省略号；并修复二级面板被主面板遮挡（毛玻璃合成层绘制顺序）导致点供应商无反应的问题
- 模型切换跨端实时同步：任一端（手机/桌面）切换模型后，其他端的模型芯片、状态栏与轮次标签立即跟随，杜绝两端显示与实际调用模型不一致
- 模型选择按钮更换为立方体盒子图标，思考强度按钮改为纯大脑图标（对齐 ZCode 交互）
- 手机端元信息条新增上下文占用百分比（超 70% 橙色、超 90% 红色，悬停查看用量详情）
- 输入框支持拖拽顶边手柄调高（最高约占窗口 60%，向下拖以默认两行高度为下限），高度自动记忆、跨启动恢复，双击恢复默认；修复拉高后下限跟着抬高导致拖不回来的问题
- 预置厂商新增「智谱CodingPlan(OpenAI)」与「智谱CodingPlan(Anthropic)」，官方路由判定覆盖 CodingPlan 套餐端点（缓存保活同待遇）；「智谱」更名为「智谱API」
- 预置厂商「基元律动」与「智谱」新增 `glm-5.3-flash` 模型（100 万上下文、支持多模态、思考档位同 glm-5.3）
- 新增智谱 GLM 前缀缓存路线：官方直连（open.bigmodel.cn）自动启用缓存保活（对齐 Kimi/DeepSeek 待遇），会话空闲一段时间后再继续对话不再整段缓存失效，命中占比可在状态栏直接对比；仅官方路由生效，第三方中转的 GLM 模型不受影响
- 保活请求适配 glm-5.3 / glm-5.3-flash 强制思考模型（这类模型拒绝关闭思考参数，原保活方式会失败）
- 回复中本地文件路径自动识别为可点击链接，点击直接预览文件内容
- 修复输入框 `/` 与 `@` 补全面板被消息区遮挡的问题
- 修复手机端状态栏精简未生效、透明主题下侧栏重叠等界面问题
- 手机/平板触摸端附件入口简化：点回形针不再弹出应用内「拍照/相册/文件」菜单，直接唤起系统选择器（iOS 三合一菜单 / 安卓文件选择），省去一次无差别中转；拍照、图片（多选）、文件统一由系统面板承接
- 优化多网卡环境下局域网 IP 探测，保证手机与电脑同一 WiFi 能正确连接
- 远程 RPC 桥接改为黑名单控制，默认放行并加线程锁保护
