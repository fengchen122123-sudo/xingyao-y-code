# Y-CODE 更新日志

## 1.2.6 (2026-08-20 23:05)

- 新增 Gitee Releases 检查更新与安装包自动下载：支持软件启动静默检查与「设置-关于」页面手动点击检查更新
- 顶部导航栏更新提示：有新版本时顶部右上角出现更新徽章与下载进度，下载完成后一键引导安装
- 任务感知安全安装防护：安装包就绪后若当前有对话或后台任务运行中，主动点击安装时二次警告确认，防止误中断工作
- 安装包生命周期自清理：唤起安装向导完成后自动删除下载的临时安装包，启动期自动扫描并清理历史临时缓存
- 内存压缩器增强：修复超长文本与非 UTF-8 二进制分块时的编码截断异常，提升上下文压缩健壮性
- 工具调度与生命周期加固：完善多会话并行与子代理状态隔离，优化文件差异对比行号计算与展示
- 界面图标精简：左侧栏菜单统一恢复为极简黑白字符风格，视觉轻量自然

## 1.2.5 (2026-08-20 16:45)

- 修复启动页偶发卡死：桥就绪判断改为方法级（get_initial_state 已注入才算就绪），消除注入中间态抢跑调用导致的永久转圈
- 预置目录新增「阶跃星辰（Anthropic格式）」厂商，含 step-explore 模型
- 基元律动预置目录新增 deepseek-v4-pro-0813 模型
- 侧栏项目分组文件夹图标支持点击在资源管理器中打开对应目录
- 消息流回合底部新增「文件更改」折叠面板：列出本回合改动的文件与增删行数（+新增 / −删除），点击文件行可展开查看红删绿增的改动详情（含真实行号，仅显示改动部分及上下 5 行）
- 修复上下文压缩后圆圈不及时更新：压缩完成后立即重算并推送上下文占用，红圈随之回落
- 修复从大窗口模型切到小窗口模型后超限报错：切换时若占用超新窗口阈值自动压缩历史；压缩判定基线改为取真实用量与本地估算的较小值，避免过期的大窗口真实基线导致压缩失效
- 修复项目内路径误弹沙盒询问：模型一次输出多个只读工具时并行执行丢失工作目录绑定，导致项目根目录被误判为"工作目录之外"（打包版 GUI 必现，子代理并行启动同样受影响）
- 修复相对路径解析错位：文件与目录工具的相对路径（含默认 "."）改按会话工作目录解析而非进程启动目录，与命令执行的 cwd 语义对齐
- 沙盒开关语义明确：解除限制后工作目录外的读写直接放行不再逐次询问；恢复限制后逐次询问（~/.ycode 凭据文件写入除外，始终询问）
- ~/.ycode 数据目录读取全面豁免：无论权限模式与沙盒开关状态，agent 读取自家运行数据（含 config.json / mcp.json 配置诊断）不再询问；仅写入凭据文件需确认，防止 MCP 配置注入与配置损坏
- 权限白名单路径规范化修复：相对路径改按会话工作目录解析，「始终允许」的授予与命中不再因进程目录漂移错位
- 同步修正权限模式下拉、设置页沙盒说明与 CLI /sandbox 帮助文案，与新沙盒语义保持一致
- 修复新会话页切换模型时页面跳转：空会话切模型不再向消息流插入"已切换活动模型"提示，空状态页保持不消失，仅模型按钮文案更新
- 模型与会话绑定：各会话（含未落库的新会话草稿）独立记录模型选择，切换会话即时恢复该会话的模型，B 会话换模型不再影响 A 会话；新建会话沿用当前会话正在使用的模型；会话绑定的模型被删除后自动回落到当前配置模型
