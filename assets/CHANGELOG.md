# Y-CODE 更新日志

## 1.2.4 (2026-08-19)

- 关闭窗口行为优化：无对话回合运行时点关闭直接退出，不再驻留后台；有回合运行时弹出确认框（最小化到托盘继续 / 停止并退出 / 取消）
- 界面图标全面升级：所有 Unicode 字符图标统一替换为矢量 SVG 图标，风格一致、缩放清晰
- 折叠体系统一：思考过程、执行轨迹、回合中间过程使用同一套折叠交互（箭头旋转动画、悬停反馈一致），总结输出时中间过程自动收起
- 修复偶发启动卡死：新增桥注入看门狗，快速重启导致启动页永久转圈的问题自动恢复
- 修复连接失败无提示：后端连接失败时启动页显示明确错误，不再无声卡住
- 修复删除会话后的冗余成功弹窗
