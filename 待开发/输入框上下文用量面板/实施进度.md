## 附：ZCode 调研要点（对照实现）

- **ZCode 侧**：输入框工具栏 14px 圆环触发器（背景圆 25% 透明 + 前景弧 70% 透明、圆头线帽、-90° 起笔）+ 悬停面板（"上下文容量"标题、`used/size (pct)` 等宽摘要、分段进度条、按来源占比列表、缓存命中率行——≥78% 才显示）；占比为**字符数估算**，仅用于展示比例、不进 token 账本。
- **星瑶侧实现同构**：圆环保留（含 >70% 橙 / >90% 红功能色）；面板含标题/摘要/分段进度条/5 类来源占比/缓存命中率；数字沿用完整千分位（不采用 K/M 缩写）；未移植 Coding Plan / Start Plan 配额段（无订阅体系）。
