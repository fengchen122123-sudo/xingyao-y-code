## 1. 任务管理

- [ ] 【自动】创建 interval/daily/weekly/startup 四类任务入库，字段完整（01 规格 7.1）。【人工】GUI 表单逐类创建成功。
- [ ] 【自动+人工】触发器配置非法（空名、0 间隔、非法 HH:MM、空 weekdays、prompt 空/超 6000、任务数超 64）保存被拒，错误逐条可读。
- [ ] 【自动】任务编辑后 next_run_at 即时重算；启停开关立即生效（禁用后到点不触发）。
- [ ] 【人工】删除任务：任务与其运行历史一起消失，进行中的该任务运行不受影响（跑完按既有终态记录）。
- [ ] 【人工】禁用任务仍可「立即执行」。

## 2. 触发与调度

- [ ] 【自动】compute_next_run：daily 当日已过取明天、恰等当前分钟取明天；interval 严格递增；weekly 周界正确；startup 返回 None。
- [ ] 【自动】next_run_at 认领为单条 CAS UPDATE；100 线程并发抢同一任务仅 1 个成功。
- [ ] 【自动】同任务存在 queued/running 运行时新触发记 skipped（error="上一次运行尚未结束"），不派发。
- [ ] 【自动】引擎主循环异常隔离：单任务分发抛错置 error，其他任务继续。
- [ ] 【自动】notify_changed 即时唤醒；无任务时空转开销为一次索引查询/30s。
- [ ] 【人工】页面明示「仅应用运行期间生效」；关闭应用期间错过：默认 skip 留痕；run_once 补跑一次且不连环。

## 3. 执行管线

- [ ] 【自动】闲会话触发：_spawn_turn_worker 收到 internal_kind="automation"、automation_run_id 正确；turn_start 带 internal/display_text。
- [ ] 【自动】忙会话触发：条目进 _message_queues，message_queue 快照推送；补发透传 automation_run_id；运行 queued→running。

- [ ] 【自动】终态 exactly-once：completed / cancelled（用户停止）/ error（turn_error）三路径各至少一个测试。
- [ ] 【人工】自动化回合在对话流以系统样式呈现（标题「自动化任务「X」」+ 完整过程），与后台总结回合观感一致。
