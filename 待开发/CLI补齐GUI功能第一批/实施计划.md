## 0. 背景与目标

功能盘点（GUI vs CLI）确认了 10 项 GUI 有、CLI 无、且可在终端形态落地的功能。
按依赖与风险分三个批次（Batch A/B/C）串行实施，每批次独立提交推送，保证任意
时刻仓库可回退、另一会话的工作不受污染。

**明确不做（本批）**
- `/queue` 的「插队（jump）」：依赖完整取消链路，且受 AGENTS.md 取消铁律约束

- LAN 手机远程、GUI 主题、托盘、图片灯箱等终端形态不适用项。
- `/changes` 不做增删行数统计，除非 turn_undo 快照已免费携带（实现时确认）。

## 3. 通用约定

1. **接入模式**：所有新命令在 `handle_slash_command`（main.py）的 elif 链加分支，
   UI 线程同步执行（与现有命令一致）；重量级操作（/update 下载）走后台线程。
2. **线程纪律（AGENTS.md 铁律）**：后台线程绝不直接 `print_formatted_text` /
   `app.invalidate()`；经 `app_instance.loop.call_soon_threadsafe(...)` 或现有
   UI 事件队列投递（参考 `core/computer/cli.py:247` 的 listener 范式）。
3. **终端输出**：`print_formatted_text(HTML(...))`，动态内容过 `_esc()`；
   不用 `**`/`*` 强调，用缩进、符号、空行。
4. **命令登记三件套**：`COMMAND_COMPLETIONS`（main.py:916 表）、`/help` 文案、
   （如适用）动态参数补全（复用 `_reasoning_options_for_completion` 的短 TTL
   缓存模式）。
5. **测试**：新文件 `tests/test_cli_parity_commands.py`（monkeypatch 打印与依赖，
   风格对齐 `tests/test_main_ui_events.py`）；computer 子命令用例加进
   `tests/test_computer_cli.py`。
6. **每批次收尾验证**：`venv/Scripts/python -m py_compile <改动文件>` +
   `pytest` 相关测试文件 + `git diff` 核对 + 提交推送。
7. 本次全部改动不触碰请求构造/system prompt/tools/metadata/extra_body，无需
   byte-golden 回归。

## 4. 功能设计

### 4.1 `/clear-history [y|yes|--force]`（Batch A）

- **行为**：清空当前会话全部消息历史，保留会话本身。无参数时打印条数与确认
  提示（`/clear-history y` 确认），带 `y|yes|--force` 直接执行。
- **依赖**：`MemoryManager.clear_session_messages(session_name)`（core/memory.py:1999，
  返回删除条数）；token 快照重置对齐 `gui_bridge.py:3054`（`core.llm` 的
  `session_token_usage` + `token_usage_lock`，latest_total/prompt/cached 归零）。
- **边界**：不存在/空会话 → 提示无历史；不删会话、不动计划与长期记忆；
  执行后 `app_instance.invalidate()` 刷新状态栏 token 环。
- **改动**：main.py（命令分支 + 补全表 + help）。

### 4.2 `/persona [name|title|text|reset] [值...]`（Batch A）

- **行为**：
  - 无参：显示当前智能体名称、对你的称呼、人设文本（超 400 字截断显示头尾）；
  - `name <名称>` / `title <称呼>`：单项修改（读旧值合并写入）；
  - `text <全文>`：整体替换人设文本，>20000 字拒绝；
  - `reset`：恢复内置默认（空人设）。
- **依赖**：`core/persona_settings.py` —— `get_persona_settings()`（:54）、
  `save_persona_settings(agent_name, persona, user_title)`（:81）。
- **生效**：保存即全局生效，下一轮请求读取；打印「下一轮请求生效」。
- **改动**：main.py；测试：show / set name / text 超限拒绝 / reset。

### 4.3 `/shell [id]`（Batch A）

- **行为**：无参列出可选命令解释器（label、命令、可用性、未安装原因）并标记
  当前项；`/shell <id>` 切换并持久化。
- **依赖**：`core/command_shell.py` —— `list_command_shell_options()`（:112）、
  `set_selected_command_shell(id)`（:241，异常 ValueError /
  CommandShellUnavailableError / CommandShellError → 友好报错）、
  `describe_selected_command_shell()`（:267）。
- **动态补全**：`/shell <前缀>` 补全可用 id（短 TTL 缓存，同 /effort 模式）。
- **改动**：main.py；测试：列表展示、设置成功、未安装报错。

### 4.4 `/open [path]`（Batch A）

- **行为**：在系统中打开（目录→资源管理器，文件→默认程序）。无参 = 当前工作
  目录；相对路径基于当前工作区解析；路径支持引号包裹。
- **依赖**：`os.startfile`（Windows 专属，非 Windows 打印提示）。
- **边界**：路径不存在 → 红字报错；异常吞掉并提示。
- **改动**：main.py；测试：mock `os.startfile`，校验绝对路径解析与错误分支。

### 4.5 `/skills refresh`（Batch A）

- **行为**：重新扫描技能目录并打印统计（内置/用户来源、启用数、总数）。
- **依赖**：`core/skills.scan_all_skills()`（:483）+ `get_active_skills_list()`（:630，
  补全菜单每次实时读取，无需额外失效）。
- **改动**：main.py `/skills` 分支加 `refresh` 子命令 + 补全表描述更新；
  测试：mock scan 后统计文案正确。

### 4.6 `/computer browser [edge|chrome]`（Batch B，唯一动 core 的项）

- **行为**：无值显示当前浏览器与可选项（含探测可用性）；带值切换默认浏览器。
- **依赖**：`core/computer/settings.py` —— `set_computer_browser(value, active_run)`
  （:203，活动 run 时抛 computer_session_busy；非法值 computer_invalid_config）、
  `load_computer_settings()`（快照含 computer_browser / browser_options）。
- **解析扩展**（core/computer/cli.py `handle_computer_command` :187）：
  现有 2-token 命令行为不变；新增 3-token 形式仅限 `browser <value>`；
  `_USAGE_TEXT` 更新；活动 run 判定复用 `_ACTIVE_RUN_STATUSES`。
- **改动**：core/computer/cli.py、main.py（/computer 描述与 help）、
  tests/test_computer_cli.py（成功 / 活动 run 拒绝 / 非法值 3 用例）。
- **纪律**：cli.py 模块注释同步更新（原「绝不修改永久设置键」改为
  「仅 browser 子命令可改浏览器选择，开关仍 GUI 专属」）。

### 4.7 `/queue [list|cancel <序号>|clear]`（Batch B）

- **行为**：list（默认）显示排队中消息（序号、来源会话、文本预览 60 字）；
  `cancel <n>` 移除第 n 条；`clear` 清空并报告丢弃条数。
- **依赖**：模块级 `msg_queue`（main.py:176，`queue.Queue`），元素
  `{"text", "was_queued", "session", "is_skill_call"?}`。`queue.Queue` 不可遍历：
  在 UI 线程内 `get_nowait()` 全量取出 → 处理 → 按原序回填（命令在 UI 线程同步
  执行，Enter 处理器是唯一 put 方，无并发窗口）。
- **改动**：main.py；测试：put 3 条 → list 显示 3 条；cancel 2 后剩余顺序不变；
  clear 后为空。

### 4.8 `/paste-image [说明...]`（Batch B）

- **行为**：抓取剪贴板图片 → 存临时 png → 拼上说明文本按普通消息入队发送，
  模型收到压缩后的图片。
- **依赖**：
  - `PIL.ImageGrab.grabclipboard()`（Pillow 已在 requirements，input_parser 在用）；
    返回 Image → 存临时文件；返回路径列表 → 直接作为消息文本里的附件路径；
    返回 None → 报「剪贴板中没有图片」。
  - 发送路径：把临时文件绝对路径嵌入消息文本（`parse_user_input` 第 2 步自动
    提取盘符绝对路径并走压缩/视觉管线，core/input_parser.py:191；worker 在
    main.py:4195 消费）——零队列结构与管线改动。
- **边界**：headless 模式提示不可用；ImageGrab 异常（无剪贴板权限等）→ 友好报错；
  临时文件不主动清理（系统临时目录自管），文档记录该取舍。
- **改动**：main.py；测试：mock `ImageGrab.grabclipboard` 返回 Image / None /
  路径列表三分支，校验入队文本含临时路径。

### 4.9 `/update [check|download|cancel|install [路径]]`（Batch C）

- **行为**：
  - `check`（默认）：显示当前版本、最新版本、更新日志（body 截断 ~40 行）、
    包大小、缓存安装包命中情况；
  - `download`：后台下载（分卷/单文件由 core 自动判定），进度按 10% 步进 +
    完成/失败打印行（后台回调经主线程代理投递，遵守线程纪律）；
  - `cancel`：取消进行中的下载；
  - `install [路径]`：无参时用最近下载完成路径，否则缓存探测
    `find_cached_installer`；门禁 = 无进行中回合（turn controller）且
    `task_manager.list_active_tasks()` 为空；y/N 确认（会退出程序）→
    `launch_installer(path)`（core/updater.py:839）→ 成功后 0.5s 延迟退出
    （对齐 `gui_bridge._delayed_exit`：优雅 close + `os._exit(0)`）。
- **依赖**：`core/updater.py` —— `fetch_latest_release()`（:369）、
  `UpdateDownloader.start_download(...)`（:547，回调 on_progress/on_complete/
  on_error）、`cancel()`（:830）、`launch_installer()`（:839）、
  `find_cached_installer()`（:284）。模块级惰性单例 downloader。
- **边界**：headless 下提示不可用；检查失败打印 msg；已是最新版本提示。
- **改动**：main.py；测试：mock fetch/downloader —— check 展示、install 门禁
  （有活动任务拒绝）、download 启动参数正确。

### 4.10 `/changes [N]`（Batch C）

- **行为**：显示最近 N（默认 1）个回合的文件变更清单：turn_id、时间、逐文件
  状态（可回滚/已回滚）与路径；引用 `/checkpoint restore <turn_id>` 提示。
- **依赖（只读）**：`core/turn_undo`（对方已落地）——
  `service.list_turn_undo_states(session_id, limit)`（main.py:1938 用法参考）、
  `service.get_turn_undo_file_diff(...)`（:339，如快照含行数则展示）。
  session_id 口径对齐 main.py 现有 `_undo_session_id(...)`。
- **边界**：无记录 → 提示；turn_undo 异常 → 友好降级提示，不影响其他命令。
- **改动**：main.py；测试：mock list_turn_undo_states 渲染 2 个回合。
