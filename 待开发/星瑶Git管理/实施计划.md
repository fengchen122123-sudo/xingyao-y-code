# 星瑶 Git 管理工作台 实施计划

> **执行方式**：按阶段滚动执行（subagent-driven-development 或 executing-plans），每阶段开工时先补全该阶段 bite-sized 步骤计划，阶段完成后在 `待开发/星瑶Git管理/实施进度.md` 记录完成范围、验证证据与下一步。步骤用 `- [ ]` 复选框跟踪。

**Goal:** 按唯一需求基线 `01-完整设计规格.md` 为星瑶 GUI 与 CLI 交付完整手动 Git 工作台，模型侧 `execute_command` 流程保持不变。

**Architecture:** 新建 `core/git/` 领域层（不可变值对象 + 单一进程执行器 + 查询/变更/补丁服务 + 双级锁协调 + 仓库信任 + 风险确认 + 外部监控），`core/worktree.py` 退化为兼容门面；GUI 经 `gui_bridge.py` 窄接口 + pywebview 事件，CLI 经严格解析的 `/git` 子命令 + 全屏管理器。以 Git 仓库为唯一事实源，快照不落盘。

**Tech Stack:** Python 3 stdlib + subprocess（参数数组，无 Shell）；Vue 3.5 + Pinia 4 + TypeScript（Vite/vitest）；prompt_toolkit（CLI 状态栏与全屏 Application）；pytest + 真实临时 Git 仓库集成测试。

## 全局约束（每个任务隐含包含）

- 最低 Git 版本 2.36.0，低于基线显式报错，不用旧命令模拟（规格 §5.1）。
- Git 一律参数数组、不用 Shell；路径参数前加 `--`；Ref 用 `git check-ref-format --branch` 校验（§8）。
- 显式失败：不自动 Stash / 强制切换 / 解决冲突 / 改 Pull 策略 / 重试网络 / 删锁文件（§4.3）。
- 不新增模型工具、不改 system prompt / tools schema；`prompt byte stability` 与 provider golden 必须保持不变（§4.4、§17.4）。
- 开发与提交只在 `dev` 分支；不合并到 `master`；开始前检查工作树，保留用户已有修改（§19、AGENTS.md）。
- GUI 事件线程不得直接 `evaluate_js`（必须走 `_js_queue`）；CLI 后台线程不得直接 `print_formatted_text` / `app.invalidate()`（AGENTS.md、§10）。
- 凭据/Token/敏感 Query 不得进入界面、日志、错误；Remote URL 脱敏（§16）。
- SQLite 如有写入必须 commit，但 Git 快照不得持久化为第二事实源（§19）。
- 高风险操作 = 服务端 preview + 60 秒一次性确认令牌，前端弹窗不算边界（§13）。
- 阶段只是降低实施风险，不得作为删减范围或分版的理由（§19）。

### 状态机（规格 §14，正交三维）

```python
class OperationKind(str, Enum): IDLE="idle"; MERGE="merge"; REBASE="rebase"; CHERRY_PICK="cherry_pick"; REVERT="revert"; UNSUPPORTED_EXTERNAL="unsupported_external"
class OperationPhase(str, Enum): NONE="none"; RUNNING="running"; PAUSED_FOR_CONFLICT="paused_for_conflict"; PAUSED_FOR_EDIT="paused_for_edit"; INTERRUPTED="interrupted"
class HeadState(str, Enum): NORMAL="normal"; DETACHED="detached"; UNBORN="unborn"
# 唯一耦合规则：kind==IDLE ⇔ phase==NONE；conflicts 独立可非空。非法组合 raise GitError(invalid_state)。
```

### 核心值对象（全部 `@dataclass(frozen=True)`，风格照 `core/harness/models.py`）

```python
@dataclass(frozen=True)
class GitError(Exception):
    code: GitErrorCode; message: str
    exit_code: int | None = None
    command_summary: str = ""      # 已脱敏
    retryable: bool = False

@dataclass(frozen=True)
class RepositoryIdentity:
    workspace_path: str; worktree_root: str; git_dir: str; common_git_dir: str
    is_bare: bool; is_linked_worktree: bool; git_version: str
    capabilities: frozenset[str]   # "status_v2","worktree","rebase_edit",...

@dataclass(frozen=True)
class FileChange:
    path: str; index_status: str; worktree_status: str
    orig_path: str | None = None; is_binary: bool = False

@dataclass(frozen=True)
class ConflictEntry: path: str; kind: str   # "both_modified"|"both_added"|"deleted_by_them"|...

@dataclass(frozen=True)
class GitSnapshot:
    repository: RepositoryIdentity; head_oid: str; branch_name: str | None
    head_state: HeadState; upstream: str | None; ahead: int; behind: int
    staged: tuple[FileChange, ...]; unstaged: tuple[FileChange, ...]
    untracked: tuple[str, ...]; ignored_count: int
    conflicts: tuple[ConflictEntry, ...]; stash_count: int
    operation_kind: OperationKind; operation_phase: OperationPhase
    identity_state: str            # "ok"|"identity_missing"
    worktree_version: str          # sha256 hex，服务端锁内计算
    refs_version: str

@dataclass(frozen=True)
class SnapshotVersions:
    worktree_version: str | None = None; refs_version: str | None = None
```

### Runner（唯一 Git 进程执行器）

```python
class ExecScope(str, Enum): READ_ONLY="read_only"; INDEX="index"; REF="ref"; WRITE="write"; NETWORK="network"
class GitRunner:
    def run(self, args: list[str], *, cwd: str, scope: ExecScope = ExecScope.READ_ONLY,
            timeout: float = 30.0, stdin: bool = False) -> GitProcessResult  # (returncode, stdout bytes, stderr bytes)
    def validate_branch_name(self, name: str) -> None        # check-ref-format --branch，失败 raise GitError(invalid_ref)
    def map_error(self, result: GitProcessResult, args: list[str]) -> GitError
```

执行规则（§8 全部落实于此）：`--no-optional-locks` 固定注入；`GIT_OPTIONAL_LOCKS=0`；status 覆盖 `core.fsmonitor=false`；diff/log/show 默认 `--no-ext-diff --no-textconv`；`protocol.ext.allow=never`；未知 Remote Helper 拒绝；stdin 默认关闭；超时杀进程树；绝不自动重试；stderr/exit → `map_error` 归类 `GitErrorCode`。
