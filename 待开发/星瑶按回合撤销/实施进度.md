## 交付结构

```
core/turn_undo/
  __init__.py        # 公共导出
  models.py          # 严格枚举、状态机迁移表、值对象、TurnUndoError（规格 5）
  storage.py         # 六表 DDL + DAO（record_version/CAS/令牌/纠正/GC）+ BlobStore（规格 7/8）
  recorder.py        # FileMutationRecorder：prepare/verify/rollback/close（规格 9）
  coordinator.py     # 规范化工作区互斥锁 + 活跃回合/撤销登记 + 冻结路径判定（规格 21）
  transaction.py     # 预检 + 一次性令牌 + 多文件恢复事务（规格 11/12）
  recovery.py        # 启动扫描 + 恢复预检/执行 continue_revert|cancel_revert（规格 13/24）
  prompt_context.py  # <workspace_correction_ledger> 动态纠正块（规格 15.3）
  service.py         # TurnUndoService 公共 API + 进程级注册 + 生命周期编排（规格 19）
```

关键接线点：

- `core/memory.py`：`create_tables` 幂等建 turn_undo 六表；`add_messages`/`add_message`/
  `add_messages_with_harness_events` 同事务写 `message_turn_links`（显式参数 → TLS →
  turn_id 查库兜底）；`mark_turn_final_assistant`、`load_session_turn_links`；
  `get_all_sessions` 附带不可变 `id`。
- `gui_bridge.py`：`_run_turn_worker` 重排（turn_id=uuid4 → 持久化 checkpoint →
  用户消息+link 落库 → 发含 session_id+turn_id 的 turn_start）；`_turn_owner_sessions`
  权限事件路由；7 个按回合撤销 Bridge 方法 + `turn_undo_updated` 事件；
  `_load_session_messages` 合并 turn 元数据；启动 configure + 恢复扫描。
- `main.py`：`_background_worker` 同序重排 + `print_turn_file_summary_if_ready` 回合摘要；
  `handle_undo_command`（/undo、list、preview、status、recover，默认确认 N）；
  `/checkpoint restore` 迁移为新服务兼容入口；启动中断摘要；undo_turn 权限卡分支。
- `core/tools.py`：`write_file`/`edit_file` 三路径/`fetch_image` 接入记录器
  （工作区锁内 prepare→write→verify，失败回滚计划记录）；`execute_command` 标记
  `has_uncovered_command_effects` 并在中断冻结期拒绝执行；新增 `undo_turn` 工具。
- `core/harness/tool_adapters.py`：`execute` 统一登记工具名+call_id TLS；删除旧
  set_undo_state 兼容记录。
- `core/tool_registry.py`：注册 `undo_turn`（schema 仅 turn_id；requires_permission=True）。
- `core/context_builder.py` + `core/agent_service.py`：RuntimeContext 新增
  `workspace_corrections`，动态块按规范化工作区追加纠正 ledger。
- 前端：pywebview.d.ts（7 个方法 + 事件/DTO 类型）；appStore（turnUndoStates、
  refreshTurnUndoStates 批量查询、preview/execute/recovery actions、turn_undo_updated
  reducer、turnId 权威绑定）；turnGroups（TurnGroupInfo.turnId）；TurnGroup（撤销状态
  传入面板）；ChangedFilesPanel（展开区/撤销按钮分离、状态机、冲突视图、恢复视图、
  惰性 diff）；PermCard（undo_turn 影响摘要）。

- fetch_image 写 `Path.cwd()`（非线程 workdir）为既有行为，本次仅按触盘点接入记录器，未改变其路径语义。
- LAN 端未做 undo 卡片 UI；新 Bridge 方法按既有动态分发对手机可用，安全门禁（后端令牌/预检）与桌面一致。
