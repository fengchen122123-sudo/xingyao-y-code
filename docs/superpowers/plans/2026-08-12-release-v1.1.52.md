# Y-code v1.1.52 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish the audited GUI/security fixes as Y-code v1.1.52 to Gitee `dev` and `master`, then produce a verified Windows installer.

**Architecture:** Keep `core/version.py` as the canonical version source and mirror it in the README badge. Validate the release tree before committing, merge the exact `dev` commit into `master`, validate the merged tree, and build all Windows artifacts from `master` with the repository release pipeline.

**Tech Stack:** Python 3.12, pytest, Vue 3/Vitest/Vite, Git/Gitee, PyInstaller.

## Global Constraints

- Commit normal development changes on `dev` first.
- Merge to `master` only because the user explicitly requested it.
- Do not stage the pre-existing `.pytest_tmp/` directory.
- Do not force-push either branch.
- The release version is `1.1.52`, following the highest version marker `v1.1.51` in recent history.
