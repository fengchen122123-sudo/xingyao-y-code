# 输入区附件与权限模式视觉设计

## 目标

简化对话输入区操作控件，并让当前权限模式无需依赖方框对勾即可被识别。空会话输入区与已有消息输入区必须保持一致。

## 视觉规则

- 附件按钮只显示全角加号 `＋`，保留“添加附件”的 title。
- 权限按钮移除最前面的方框对勾，只显示模式名称和下拉箭头。
- 当前权限模式直接决定按钮的边框、文字与柔和背景色：
  - `confirm`（变更前确认）：绿色 `var(--green)`。
  - `auto`（自动接受编辑）：青色 `var(--cyan)`。
  - `plan`（计划模式）：紫色 `var(--purple)`。
  - `full`（完全访问/YOLO）：红色 `var(--red)`。
- 权限下拉中的模式圆点沿用同一色表，确认模式从黄色改为绿色。
- 下拉菜单右侧的当前选中勾保留；本次只移除输入按钮前方的方框对勾。

## 实现边界

- `KimiEmptyState.vue` 与 `InputArea.vue` 使用相同的 `permission-mode-btn` 和 `perm-*` 类。
- 共享颜色规则放在全局样式中，不复制 TypeScript 颜色映射，不新增组件。
- 不改变附件选择、权限切换、发送消息和权限持久化逻辑。

## 验证

- 组件测试覆盖两套输入区的加号、无前置对勾和四种权限类切换。
- 权限下拉测试确认 `confirm` 圆点使用绿色。
- 运行完整前端测试、生产构建，并在真实 GUI 中切换四种模式检查颜色。
