# 模型级联菜单行对齐设计

## 目标

对话页悬停厂商时，让二级面板中的第一个模型条目与该厂商条目垂直对齐，避免主菜单向上展开时二级面板仍按底部对齐而产生明显错位。

## 方案

- 主厂商菜单继续沿用现有锚点、上下展开方向和视口高度计算，不改变其稳定位置。
- 悬停厂商时读取厂商条目的视口坐标，将二级面板设为固定定位。
- 二级面板顶部扣除自身边框与内边距，使第一个模型条目的顶部与厂商条目顶部一致。
- 二级面板最大高度取其对齐位置到视口底部安全边距的剩余空间；模型过多时仅在二级面板内部滚动。
- 每次打开菜单清空当前厂商和二级面板位置，避免复用上一次悬停状态。

## 测试

- 组件测试模拟厂商条目坐标，验证二级面板顶部位置和最大高度。
- 保留主菜单向上展开及视口高度约束测试。
- 运行完整前端测试、生产构建，并在真实浏览器中悬停厂商核对对齐效果。
