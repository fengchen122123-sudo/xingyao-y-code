# 系统设置紧凑列表设计

## 目标

将“系统设置”由卡片和多选项列表改为紧凑的参数行布局，让命令解释器选择只占一行，并为后续系统级参数提供可复用的呈现方式。

## 布局

- 保留页面标题“系统设置”和右上角刷新检测按钮。
- 设置主体为无外层大卡片的列表；每个设置项由细分隔线分开。
- 每行左侧显示设置名称和简短说明，右侧显示选择控件。
- 窄屏时右侧控件换到下一行，仍保持可用。

## 命令解释器项

- 名称为“默认命令解释器”。
- 说明明确其影响 AI 命令、后台任务、计划验证和右侧终端。
- 使用原生 select 控件列出 auto、pwsh、powershell、cmd 等后端提供的选项。
- 不可用选项在下拉中禁用，并在选项文本中标示“未安装”。
- 保存中禁用选择控件；保存失败时在列表下方显示错误。
- 刷新按钮重新探测解释器可用性，不改变当前选择。

## 扩展约定

后续系统级参数以同样的 `setting-row` 结构追加：左侧文案、右侧控件、可选的紧凑状态信息；不再为单个参数新增整块卡片或单独页面。

## 不变约束

- 后端设置快照和解释器执行行为不变。
- 不可用解释器仍禁止保存。
- 不新增第三方前端依赖。
