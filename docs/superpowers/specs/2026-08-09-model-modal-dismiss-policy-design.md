# 模型弹窗关闭策略设计

## 目标

添加或编辑模型时，点击弹窗外部遮罩不得丢失正在填写的内容。弹窗只允许通过右上角关闭按钮、取消按钮，以及保存成功后关闭。

## 方案

- 删除模型弹窗遮罩层的自点击关闭绑定，遮罩仍覆盖页面并拦截背景交互。
- 保留右上角关闭按钮和取消按钮调用 `closeModelModal()`。
- 保留提交成功后调用 `closeModelModal()`；提交失败继续保持弹窗打开。
- 不改变其他预览、环境变量或权限确认弹窗的关闭策略。

## 验证

- 组件测试打开模型弹窗并点击遮罩，断言弹窗仍存在。
- 组件测试分别点击关闭与取消，断言弹窗关闭。
- 保留现有保存失败不关闭测试，并运行完整前端测试与生产构建。
- 在真实 GUI 中点击遮罩、关闭和取消，核对三个交互路径。
