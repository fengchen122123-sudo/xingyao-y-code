# 明亮海岸卡通：SVG 鹈鹕骑自行车动态单文件页面设计

日期：2026-10-24

状态：已批准设计，本次仅文档化，不实现页面

## 1. 目标与交付边界

### 1.1 目标

制作一个“明亮海岸卡通”风格的 2D 动态单文件页面：一只鹈鹕骑着自行车沿海岸公路前行，天空、海洋与公路明快清新，骑行动作连贯，背景具有多层无缝视差。页面兼具暂停、继续、调速、响应式布局和减少动态效果支持。

最终页面应满足：

- 使用内联 SVG 绘制全部场景，以内联 CSS 和 JavaScript 完成样式与动画；
- 单个 HTML 文件即可通过本机浏览器打开，不依赖网络、外部图片、字体、脚本、样式表或运行时包；
- 动画具有明确统一的机械关系，而不是互不相关的装饰性摆动；
- 暂停、继续、调速以及后台标签页恢复时，画面位置与动作相位不跳变；
- 常态播放只更新必要的 SVG `transform`，避免布局抖动和 DOM 重建。

## 2. 视觉设计

整体采用高亮度、低写实的海岸卡通语言：浅青天空、 turquoise 海水、暖白沙岸、珊瑚橙自行车、白色鹈鹕与橙黄色大嘴。轮廓使用深蓝灰色圆角描边，色块简洁，明暗主要由少量纯色层次表达，不依赖高成本滤镜。

画面为横向海岸侧视图，自行车和鹈鹕保持在画面中央安全区域，车轮与路面的接触位置稳定。远景包含太阳、云朵、海平线和低矮海岸；中景包含两层海浪与道路另一侧的护栏；近景包含公路标线、路缘和少量花草。鹈鹕身体略向前倾，脚稳稳踩在脚踏上，翅膀轻摆，头部与颈部保留鹈鹕和长嘴的辨识度。

视觉动效遵守“骑行主体清晰、背景连贯但不抢戏”的原则。身体起伏、翅膀和头部摆动幅度均小于脚踏动作的视觉幅度，不做夸张弹跳或闪烁。

## 3. 方案取舍

| 方案 | 优点 | 局限 | 决定 |
| --- | --- | --- | --- |
| 纯 CSS 动画 | 声明简单，浏览器可自动优化，适合简单循环 | 多个关键帧动画难以共用累计路程；车轮、曲柄、双脚和反向视差的精确联动复杂；调速与后台恢复时的相位连续性不够直观 | 不作为场景主动画方案；CSS 只负责静态样式、布局、媒体查询和控件状态 |
| 单一 `requestAnimationFrame` | 可统一计算路程和全部关节相位；容易实现暂停、连续调速、视差取模和降级；浏览器对齐绘制帧 | 需要主动控制节点数量、时间基准和异常恢复 | 采用，且全页只允许一个场景动画调度器 |
| SMIL | 可直接描述 SVG 位移和旋转，声明式动画直观 | 多组动画的统一时钟、机械联动、交互调速和减少动态效果控制较分散；与脚本状态协同反而增加复杂度 | 不采用 |

最终采用“静态内联 SVG + 单一 rAF 数据流 + CSS 响应式布局”。不混用 CSS 场景动画、SMIL、`setInterval` 或第二条 rAF 循环，避免出现多个时间源。

## 4. SVG 结构与分层

SVG 采用固定逻辑坐标系，例如 `viewBox="0 0 1440 900"`，配合 `preserveAspectRatio="xMidYMid meet"` 等比缩放。根 SVG 提供可访问的 `<title>` 与 `<desc>`，装饰性内部节点不重复暴露给辅助技术。

从后到前的主要层级如下：

| 层级 | 内容 | 动态方式 |
| --- | --- | --- |
| `defs` | 颜色渐变、云/海浪/路面图块、内部 `<use>` 引用、必要裁剪路径 | 初始化后不变 |
| 天空 | 天空底色、太阳、远处海岸 | 静态 |
| 远云与近云 | 两组不同形状和周期的重复云图块 | 低位移系数水平视差 |
| 海面 | 海水底色、海平线 | 静态 |
| 远浪与近浪 | 两层周期完全一致、首尾可拼接的波浪图块 | 不同位移系数水平视差 |
| 道路远侧 | 护栏、草丛和路肩 | 中速视差 |
| 公路 | 路面底色、重复车道标线、近侧路缘 | 路面静态，标线和近侧路缘按不同系数视差 |
| 自行车 | 车轮、车架、链条、牙盘、曲柄、脚踏 | 车轮与曲柄旋转，脚踏平移并保持水平 |
| 鹈鹕 | 远侧腿、身体、近侧腿、翅膀、颈部、头部、嘴和眼睛 | 身体起伏，腿部随脚踏求解，翅膀与头部轻摆 |
| 前景 | 少量不遮挡主体的花草或沙砾 | 近景视差 |

每个可动部件在自身局部坐标系中以关节为原点。例如，轮辐组以轮心为原点，曲柄组以中轴为原点，翅膀以肩部为原点，头部以颈部连接点为原点。父组负责定位，子组负责旋转，避免依赖浏览器不一致的 CSS `transform-origin` 行为。

身体起伏父组只承载躯干、髋部、翅膀和头部，不承载自行车与双脚。双脚始终由脚踏位置决定，腿部再连接当前髋部与脚部，因而身体起伏不会把脚拉离脚踏。远侧腿与近侧腿使用不同明度并分别安排遮挡层级。

## 5. 动画数据流与机械联动

### 5.1 单一状态源

场景动画只维护一份核心状态：

- `distance`：累计路程，使用 SVG 逻辑单位，不在暂停或调速时归零；
- `speed`：速度倍率，默认 `1`，仅影响之后的路程增量；
- `lastTimestamp`：上一有效 rAF 时间戳，暂停、后台和恢复时清空；
- `userPaused`：用户是否明确暂停；
- `reducedMotion`：系统是否要求减少动态效果；
- `frameId`：当前唯一待执行 rAF 的标识，无待执行帧时为空。

所有旋转、起伏和视差均从 `distance` 及其派生相位计算。禁止用 `Date.now()`、独立 CSS 动画或另一个计时器推动部分部件。

数据流为：

```text
rAF 时间戳 → 有效帧间隔 → 累计路程 distance
                         ├─ 车轮角 → 曲柄角 → 左右脚踏位置 → 双脚与双腿
                         ├─ 身体、翅膀和头部的低幅相位
                         └─ 云、海浪、护栏、标线、路缘的取模位移

按钮/滑块/可见性/系统动态偏好 → 更新状态与调度，不直接改写关节位置
```

### 5.2 时间推进

以秒为单位计算帧间隔。正常前台帧使用：

```text
rawDelta = (now - lastTimestamp) / 1000
delta = clamp(rawDelta, 0, 0.05)
distance += delta * baseVelocity * speed
```

`baseVelocity` 是 1 倍速下的基准前进速度。首个回调只建立时间基准，不增加路程。`0.05` 秒上限用于吸收前台长任务造成的异常大间隔；后台间隔不依靠该上限处理，而是在可见性事件中直接停止计时并重置基准。

若时间戳或计算结果不是有限数值，则丢弃本次增量、清空时间基准并保持上一有效画面。每帧结束后，在仍需动画且没有待执行帧的前提下请求下一帧。

### 5.3 车轮、曲柄、脚踏与双脚

设车轮半径为 `R`，前轮链轮与后飞轮的传动比为 `G = 前链轮齿数 / 后飞轮齿数`，则：

```text
wheelAngle = distance / R
crankAngle = wheelAngle / G
```

实际写入 SVG 时再把弧度转换为角度，方向统一为向前骑行对应的旋转方向。两个车轮使用相同半径和角速度，曲柄严格跟随传动比，不另设自由运行周期。

设中轴为 `B`、曲柄半径为 `r`，左右曲柄相位相差 `π`：

```text
rightPedal = B + r * (cos(crankAngle),     sin(crankAngle))
leftPedal  = B + r * (cos(crankAngle + π), sin(crankAngle + π))
```

脚踏节点只更新平移 `transform`，保持踏板接近水平，不继承曲柄组的旋转。左右脚分别绑定左右脚踏，脚底参考点与踏板参考点重合。

双腿采用固定腿长、两节骨骼的平面逆运动学。以当前髋点为起点、对应脚踏为终点，使用大腿长 `L1` 和小腿长 `L2` 求膝点；膝部始终选择向前弯曲的同一分支，避免跨帧翻面。几何参数必须保证整个曲柄周期内，髋到踏板的距离位于 `[abs(L1-L2) + ε, L1+L2 - ε]` 的可达范围；求解时仍进行同样的数值钳制以防止浮点越界，但正常运行不得依靠钳制改变脚踏位置或实际腿长。大腿和小腿均使用固定长度的局部 SVG 节点，通过各自的 `translate(...) rotate(...)` 连接关节，不在每帧重写路径数据。

### 5.4 身体、翅膀与头部

身体起伏使用 `bob = bobAmplitude * sin(2 * crankAngle)`，对应每圈曲柄两次踩踏。翅膀以肩部为轴进行低幅旋转，头部以颈部为轴进行反向或带相位差的轻摆，两者频率均从 `crankAngle` 派生。

这些部位不读取独立 elapsed time，因此调速只改变后续相位推进速度，不会改变当前姿态；暂停时全部部位同时冻结。

### 5.5 多层无缝视差

每个移动层拥有固定的重复图块宽度 `W` 和视差系数 `k`，位移为：

```text
offset = (distance * k) mod W
layerTransform = translate(-offset, 0)
```

建议由远到近逐步增大系数：远云、近云、远浪、近浪、道路远侧、车道标线、近侧路缘。自行车主体保持固定，车道标线的系数接近 `1`，从而建立向前骑行的视觉关系。

每层使用内部 `<use>` 重复同一图块，覆盖当前视口及前后至少一个完整图块。图块左右边缘的高度、切线、颜色和重复元素位置必须一致；当 `offset` 从接近 `W` 回到 `0` 时，相邻相同图块恰好接替，画面不可出现空档或跳变。图块几何在初始化时固定，播放过程中不随机生成元素。

## 6. 调度、交互与连续性

### 6.1 暂停与继续

- 暂停时记录 `userPaused = true`，取消唯一待执行 rAF，清空 `lastTimestamp`，保留 `distance` 与所有当前 `transform`；
- 继续时清空时间基准并只请求一个 rAF，首个回调不推进路程，从第二个有效间隔继续；
- 重复点击、可见性事件与恢复事件不得产生并行 rAF；调度前先检查 `frameId`；
- 按钮使用原生 `<button>`，可见文字与无障碍名称在“暂停动画”和“继续动画”之间同步更新。

### 6.2 速度滑块

使用原生 `input[type="range"]`，建议范围 `0.25` 至 `2` 倍速，步进 `0.05`，默认值 `1`。提供关联标签和当前倍率输出，支持键盘、触摸和鼠标。

`input` 事件只校验并更新 `speed` 与倍率文本，不重置 `distance`、车轮角、曲柄角、图层偏移或上一帧时间戳。于是位置与姿态保持连续，仅后续速度发生变化。非法或非有限输入被钳制到有效范围，不进入动画状态。

### 6.3 后台与页面恢复

- `document.hidden` 变为 `true` 时取消待执行 rAF、清空 `lastTimestamp`，保留用户暂停状态和累计路程；
- 页面重新可见时，仅在用户未暂停且未启用减少动态效果的情况下重新调度，首帧只建立新时间基准；
- `pagehide` 采用同样停止策略，`pageshow`（包括前进后退缓存恢复）清空旧时间戳并按当前状态重新调度；
- 后台停留时长不折算成路程，恢复时不能突然追赶动画。

## 7. 响应式、无障碍与减少动态效果

### 7.1 响应式

- 页面包含正确 viewport 元信息，主体宽度不超过视口，不产生横向滚动；
- SVG 通过 `viewBox` 等比缩放，完整保留车轮、鹈鹕和长嘴，不在窄屏裁掉关键主体；
- 控件区使用可换行的弹性布局，窄屏下暂停按钮和速度控件纵向排列；
- 控件触控目标至少 `44 × 44` CSS 像素，文本与背景保持清晰对比；
- 布局由 CSS 和媒体查询完成，动画帧内不读取布局尺寸，也不根据窗口大小区间创建另一套动画。

### 7.2 无障碍与静态内容

SVG 提供“明亮海岸边，一只鹈鹕骑着自行车”的标题及更完整描述。所有交互均可通过键盘完成，焦点样式清晰，速度倍率文本不会每帧刷新或持续触发读屏播报。

即使 JavaScript 被禁用或初始化失败，内联 SVG 仍应显示完整静态画面。控件只有在初始化成功后才启用；不可用时提供简短状态说明，而不是留下看似可点击但无反应的按钮。

### 7.3 `prefers-reduced-motion`

同时通过 CSS 媒体查询和 JavaScript `matchMedia('(prefers-reduced-motion: reduce)')` 响应系统偏好：

- 初次加载命中 `reduce` 时，只显示完整静态画面，不启动 rAF，动画控件禁用并说明原因；
- 播放过程中系统切换为 `reduce` 时，立即在当前姿态停止，保留累计路程，不闪回初始帧；
- 系统切回 `no-preference` 后恢复控件可用性，但不自动播放，由用户明确选择继续；
- CSS 同时关闭非必要的界面过渡，不用平滑滚动或闪烁提示替代动画。

## 8. 性能约束与异常降级

### 8.1 每帧更新边界

初始化时一次性缓存所有需要更新的 SVG 节点引用及固定几何常量。每帧只允许：

1. 计算新路程和各派生相位；
2. 对实际运动的节点写入必要的 `transform`；
3. 请求下一帧或按状态停止。

每帧禁止执行 `querySelector`、创建或删除节点、重建 SVG、设置 `innerHTML`、重写字体/布局样式、读取 `getBoundingClientRect()` 或重写路径 `d`。速度文本只在滑块输入时更新。可对 transform 数值统一保留合理精度，并在值未变化时跳过写入。

优先使用简单色块、圆角描边和内部复用图块，不使用每帧变化的大面积模糊、位移滤镜或昂贵混合模式。静态结构和动态节点分离，避免为了动画重新解析整个 SVG。

### 8.2 异常与降级

| 情况 | 行为 |
| --- | --- |
| JavaScript 禁用 | 显示完整静态 SVG；不展示可操作的动画控件 |
| 必要 SVG 节点缺失或初始化校验失败 | 不启动动画，保留静态画面，禁用控件并给出简短说明 |
| rAF 不可用 | 保留静态画面和可访问说明，不尝试高频定时器替代 |
| 单帧出现非有限数值 | 丢弃该增量并清空时间基准，不写坏节点 transform |
| 帧更新抛出异常 | 取消调度，保留最后有效画面，显示动画已停止的说明；不建立重试循环刷屏 |
| 标签页后台或页面进入缓存 | 停止计时，不累计后台时间 |
| 系统要求减少动态效果 | 停止场景运动，保持静态画面 |
| 最终 HTML 路径已有同名文件 | 停止保存并报告，不覆盖或删除原文件 |

运行期错误信息不插入不受信任的 HTML；状态提示只使用固定文本和 `textContent`。

### 9.2 本机浏览器验证
