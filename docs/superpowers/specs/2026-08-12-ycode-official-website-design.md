# YCode 官网设计规格

日期：2026-08-12
状态：已确认，待实施
视觉方向：A「星海指挥舱」

## 1. 目标

为 YCode 建设一个独立、可部署的中文单页官网。官网需要同时完成三件事：

1. 清楚说明 YCode 是能执行任务、理解项目并长期记忆的本地 AI 编程伙伴；
2. 通过「星瑶」正面角色形象建立独特、可信的品牌人格；
3. 引导访客下载 Windows 版本，并为后续接入真实服务器下载地址预留明确配置入口。

首版以个人开发者为主要受众，同时保证专业开发团队能快速理解产品能力。成功标准是：访客在首屏理解产品定位，在能力区获得理性说服，在星瑶区建立品牌记忆，并能顺利完成模拟下载流程。

## 2. 范围

### 2.1 本期包含

- 独立官网目录与构建配置，不改造现有桌面端 Vue 前端；
- 单页响应式官网；
- 使用现有 YCode Logo；
- 基于用户提供的参考图与仓库现有星瑶素材，生成一张星瑶正面半身主视觉；
- 首屏、产品能力、星瑶介绍、下载区、页脚；
- Windows 模拟下载交互；
- macOS 与 Linux「敬请期待」状态；
- 可通过单一配置将模拟下载切换为真实文件地址；
- 基础 SEO、社交分享元数据、键盘访问和移动端适配；
- 本地构建与浏览器视觉验收。

### 2.2 本期不包含

- 后端服务、数据库、用户账户或下载统计；
- 真实安装包托管与 CDN；
- macOS 或 Linux 安装包；
- 在线文档站、博客、价格页或多语言；
- 自动更新、版本 API、邮件订阅或埋点系统；
- 官网发布上线。待用户具备服务器后再接入真实下载与部署。

## 3. 品牌与视觉

### 3.1 核心方向

采用「星海指挥舱」：深邃夜空、冷青色能量光、精密轨道线与克制的玻璃质感。整体应有电影感和技术可信度，不做拥挤的赛博朋克，也不做通用 SaaS 蓝紫渐变模板。

配色以近黑蓝 `#020713`、深海蓝 `#041728`、高亮青 `#26DCFF`、冷白 `#F1FAFF` 和灰蓝正文 `#8FA7BA` 为主。青色只用于 Logo、关键状态和主要行动按钮，避免全页高饱和。

标题使用紧凑、现代的无衬线中文字体栈；终端片段使用等宽字体。背景以 CSS 渐变、微弱星点和轨道线构成，不使用大量装饰图片。

### 3.2 Logo 使用

复用仓库当前 Logo 资产，不重新设计标志。导航使用像素机器人标志与 `YCODE` 字标组合；页脚可同时出现「YCODE · 星瑶」。Logo 需要具备清晰的替代文本，不能只依赖背景图呈现。

### 3.3 星瑶正面画像

生成一张用于官网首屏的正面半身动漫角色插画。参考输入包括：

- 用户提供的星瑶侧脸图片；
- `assets/ycode.png` 与 `assets/ycode_rounded.png` 中的现有品牌造型。

必须保持的角色特征：深海蓝长发、蓝青色眼睛、白色翼形耳机、耳机上的像素机器人标志、白色服装、青色能量装饰、少量金属金色细节、沉静友善的神态。构图为正面或极轻微三分之二正面，视线面向访客，上半身完整，边缘留足页面合成空间。

画面不包含文字、水印或额外角色；不改变 Logo；不采用过度性感化服装或夸张战斗姿态。最终图片以项目资产形式保存，不依赖生成工具的临时目录。

## 4. 页面信息架构

页面按以下顺序组成一条下载转化路径：

### 4.1 顶部导航

- 左侧：Logo + `YCODE`；
- 中右：产品能力、星瑶、下载三个页内锚点；
- 右侧：强调按钮「下载 YCode」；
- 页面滚动后导航保持可见，并使用半透明深色背景提升可读性；
- 移动端收敛为 Logo、下载按钮与菜单按钮。

### 4.2 首屏 Hero

左侧内容：

- 状态标签：「星瑶已上线 · YCode 1.1」；
- 主标题：「让代码，回应你的想象。」；
- 产品说明：「一位真正能执行任务、理解项目并长期记忆的本地 AI 编程伙伴。从一个想法，到可以运行的作品。」；
- 主按钮：「Windows 免费下载」；
- 次按钮：「认识星瑶」。

右侧展示星瑶正面半身画像，背后使用青色光晕与精密轨道圆环。首屏必须在常见桌面尺寸内同时看到主标题、说明和主下载按钮。

### 4.3 产品能力

区块标题：「不是只回答。是把事情做完。」

用三张能力卡解释核心价值：

1. 从计划到交付：读取代码、修改文件、运行命令并验证结果；
2. 理解你的项目：长期记忆重要决定、偏好与上下文；
3. 多代理并肩工作：探索、实现、测试与审查可并行推进。

卡片允许轻微悬停高亮和细节位移，但不能依赖悬停才能读到信息。文案只陈述仓库当前已存在的能力，不添加未经实现的产品承诺。

### 4.4 星瑶介绍

采用双栏结构：角色局部视觉 + 品牌说明。核心文案为：

> 你负责想象，剩下的交给我们。

说明星瑶不是装饰性吉祥物，而是 YCode 的人格化界面：沉静、敏锐、可信，陪伴用户穿过复杂代码。下方展示一个短终端片段：

```text
❯ ycode
星瑶：已理解项目。我们从最关键的问题开始。
```

### 4.5 下载区

标题：「准备好，与星瑶并肩了吗？」

提供三个平台状态：

- Windows：可点击，首版执行模拟下载；
- macOS：不可下载，显示「敬请期待」；
- Linux：不可下载，显示「敬请期待」。

### 4.6 页脚

包含品牌署名、当前年份、页内导航和预留链接位置。没有真实地址的外部链接不伪造跳转，使用禁用或隐藏状态；后续配置真实 URL 后再启用。

## 5. 交互设计

### 5.1 页内导航

点击导航项平滑滚动到相应区块。需尊重用户的 `prefers-reduced-motion` 设置；用户要求减少动画时直接跳转，不播放滚动或入场动画。

### 5.2 模拟下载

下载信息集中在一个类型明确的配置对象中，至少包含：

- `mode`: `demo` 或 `live`；
- `windowsUrl`: 真实下载地址，演示模式为空；
- `version`: 页面显示版本；
- `fileName`: 安装包文件名。

当 `mode` 为 `demo` 时，点击 Windows 下载按钮打开一个轻量对话框，明确提示「当前为官网演示版，下载通道尚未接入服务器」，并提供「我知道了」关闭按钮。不得伪造已下载成功，也不得生成无意义安装包。

当 `mode` 为 `live` 时，必须要求 `windowsUrl` 为非空的 `https://` 地址；配置无效时在构建或启动阶段直接暴露错误，不静默回退到演示模式。有效时点击按钮使用浏览器原生导航发起下载。

macOS 与 Linux 使用禁用按钮并提供明确文本，不触发对话框或假下载。

### 5.3 动效

- 首屏星点、光晕和轨道线使用缓慢、低幅度动画；
- 内容区使用短距离淡入；
- 卡片悬停最多上移 4px；
- 所有动画不阻塞内容，不影响按钮点击；
- `prefers-reduced-motion: reduce` 下关闭非必要动画。

## 6. 技术结构

官网放在仓库新目录 `website/`，与 `frontend/` 桌面端隔离。采用独立 Vite + Vue 3 + TypeScript 项目，保持与现有前端技术栈一致，但拥有独立的 `package.json`、入口、样式、测试和构建产物。

建议模块边界：

- `src/App.vue`：页面组合与区块顺序；
- `src/components/`：导航、首屏、能力、星瑶、下载对话框、页脚；
- `src/config/download.ts`：唯一下载配置入口与严格校验；
- `src/assets/`：Logo、星瑶正面画像和分享图；
- `src/styles/`：设计变量、全局样式和动画；
- `src/**/*.test.ts`：下载配置与关键交互测试。

页面不需要路由、状态管理、后端请求或外部 UI 框架。尽量使用原生 CSS 和语义化 HTML，控制首屏资源体积。图片提供现代格式并设置合理尺寸，防止布局抖动。

## 7. 响应式与可访问性

- 桌面端以左右分栏 Hero 为主；
- 平板缩小画像并保持主行动按钮在首屏；
- 手机端改为单栏，文案在前、角色在后，能力卡纵向排列；
- 交互目标最小尺寸 44px；
- 所有按钮可通过键盘操作，焦点样式清晰；
- 下载对话框打开后聚焦标题或关闭按钮，`Escape` 可关闭，关闭后焦点返回触发按钮；
- 正文与背景达到 WCAG AA 对比度；
- 装饰星点与轨道对辅助技术隐藏；
- 图片有准确替代文本，纯装饰图使用空替代文本。

## 8. SEO 与元数据

页面语言为简体中文。标题和描述明确包含 YCode、星瑶和 AI 编程助手。配置规范 URL、主题色、Open Graph 与 Twitter Card 元数据。生成一张与首屏同风格的社交分享图，画面包含品牌识别但不依赖模型生成小字号文字。

## 9. 错误处理原则

遵循项目的 Let it crash 原则：

- 真实下载模式配置缺失或 URL 非 HTTPS 时直接报错；
- 图片资产缺失时构建失败，不以远程占位图兜底；
- 不为未知平台猜测下载地址；
- 不静默吞掉下载配置问题；
- 演示模式在界面上明确说明，不伪装真实下载。

## 10. 验证方案

### 10.1 自动验证

- TypeScript 编译与生产构建成功；
- 下载配置校验测试：演示模式、有效真实地址、空地址、非 HTTPS 地址；
- 下载交互测试：演示对话框打开和关闭、`Escape` 行为、焦点返回；
- 平台状态测试：Windows 可用，macOS/Linux 禁用；
- 关键页面文案与锚点存在。

### 10.2 浏览器验证

- 桌面、平板、手机三个尺寸无横向溢出；
- 首屏层级、星瑶裁切、Logo 清晰度和文本对比度正确；
- 导航、页内滚动、模拟下载对话框与键盘操作可用；
- 减少动画模式生效；
- 刷新后无控制台错误；
- 生产构建预览与开发环境视觉一致。

## 11. 验收条件

满足以下条件即视为首版完成：

1. 官网可在 `website/` 独立安装、开发和构建；
2. 视觉符合已确认的 A「星海指挥舱」方向；
3. 当前 Logo 被正确复用，星瑶正面画像符合既有角色特征；
4. 单页完整覆盖首屏、能力、星瑶、下载和页脚；
5. Windows 模拟下载提示清楚，macOS/Linux 状态准确；
6. 切换到真实下载只需修改单一配置，错误配置会直接失败；
7. 自动测试、生产构建和浏览器验收全部通过；
8. 不修改现有 YCode 桌面端功能和构建行为。
