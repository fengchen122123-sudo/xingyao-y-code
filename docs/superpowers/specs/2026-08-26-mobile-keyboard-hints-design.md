# 手机端隐藏键盘快捷键提示设计

## 目标

在手机宽度下隐藏输入区底部的 `Enter 发送`、`Shift+Enter 换行` 和 `Esc 中断` 说明，减少输入区拥挤；桌面端继续显示现有快捷键说明。

## 范围

- 只调整输入区快捷键提示的响应式显示。
- 使用项目现有的手机断点 `max-width: 768px`。
- 不修改输入、发送、换行和中断的实际键盘行为。
- 不修改桌面端布局，也不顺带调整其他手机端控件。

## 实现设计

保留 `InputArea.vue` 中现有快捷键提示结构，在全局移动端媒体查询中隐藏对应的快捷键提示容器。这样不复制组件、不引入运行时设备判断，并确保大于 768px 的桌面样式完全沿用当前实现。

## 验收标准

1. 视口宽度不超过 768px 时，三项快捷键说明均不可见，且不占据布局空间。
2. 视口宽度大于 768px 时，三项快捷键说明保持可见，外观与当前版本一致。
3. 输入框、发送按钮以及 Enter、Shift+Enter、Esc 的既有行为不变。
4. 前端构建和相关测试通过。

## 风险与边界

该修改依赖快捷键提示已有的独立容器选择器。若组件结构以后调整，应同步维护移动端隐藏规则。此次不处理截图中权限按钮换行、模型选择器宽度或底部状态栏拥挤问题。
